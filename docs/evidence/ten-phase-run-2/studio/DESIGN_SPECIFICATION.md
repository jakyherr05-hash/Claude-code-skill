# Design Specification - Halde (one page, index.html)
_Owner: ui-ux · Phase 4 · Numbers (type sizes, gutters, section padding) live in TYPOGRAPHY_SYSTEM.md / SPACING_SYSTEM.md; this file owns composition._
## 1. Sitemap, anchors, landmarks
`#top` (body/header target) > `#process` (section) > `#contact` (section). Landmarks: `<header>` (banner), `<nav aria-label="Primary">`, one `<main id="main">`, `<footer>` (contentinfo). Skip link is the first focusable element: `<a class="skip" href="#main">Skip to content</a>`, hidden off-screen until :focus-visible, then shown top-left as a clay/ink mat with glaze ring. `<main tabindex="-1">` receives focus on skip.
Heading outline: h1 "Halde" (hero only) > h2 "How we work" (visually-hidden allowed, `.sr-only`) > h3 per step (01 Taste, 02 Throw, 03 Glaze) > h2 contact line. No skipped levels.
## 2. Header / nav (all widths, same pattern: no hamburger, only 2 links)
Sticky, `position:sticky; top:0`, height 56px (390) / 64px (>=768), clay ground, 1px rim hairline bottom, no shadow. Left: wordmark link "Halde" to `#top` (small serif). Right: "Process" (`#process`), "hei@halde.example" (mailto; at 390 shows as "Contact" to fit, aria-label "Email hei@halde.example"). Links are tracked-caps labels, min target 44x44px (padding, not font size). Current section: `aria-current="location"` on the active link (set by JS from IntersectionObserver or ScrollTrigger; style = 1px glaze underline offset 6px, not colour alone). Anchor offset: `scroll-margin-top` = header height + 16px on `#process`, `#contact`. Header never animates (Direction: nav never moves). No focus trap needed (no overlay).
## 3. Page grid (composition)
- **<1024 (390 / 768)**: single column, DOM order = hero, plate figure, process, contact. Plate inline, static, already true and glazed. Side padding per SPACING_SYSTEM.
- **>=1024**: `<main>` becomes a 2-col grid (approx 7fr/5fr). Hero col 1 row 1; process col 1 row 2; contact spans `1 / -1`, row 3. The plate lives in a wrapper `<div class="plate-col">` placed in col 2, `grid-row: 1 / 3` (rows 1-2 ONLY, never row 3), `align-self:stretch`. The plate inside it is `position:sticky; top: header + 24px`. Sticky's containing block is `.plate-col` (not `<main>`), so the plate releases at the bottom of the process row and settles glazed ABOVE contact; it must never overlap or cover the contact CTA at any scroll position. The plate is ONE DOM node (no duplicate); CSS places it. No pinning, no scroll-jack.
## 4. Sections
**Hero** `<section id="top-hero" aria-labelledby="h1">`. Job: say who/what and put the email in reach. Content: h1 "Halde" (giant serif), `<p class="lede">` "Plates thrown by two potters in Bergen, glazed for one kitchen: yours." (italic on one phrase), CTA `<a class="cta" href="mailto:hei@halde.example">Write to us: hei@halde.example</a>`, tracked-caps eyebrow "Keramikk · Bergen".
- 390x844: eyebrow, h1, lede, CTA all above the fold; plate fully visible above the fold (no peek; accepted in critique r1 #6; the hairline and "How we work" at the fold invite scroll). CTA full-width, 48px tall.
- 768 portrait: h1 spans ~90% of the content width (fluid, ~260-290px cap height-wise per typography), lede (max ~34ch) below, CTA auto-width, plate may be grazed by the fold by ≤15% of its diameter (measured build: ~12%, accepted by creative-director; still reads as one whole object), left-aligned to the same left axis as h1/lede/CTA (not centred on a different axis).
- 1024x768 landscape (short): 2-col; h1 + lede + CTA fit within 768 minus 64 header with the plate top visible at right; hero min-height is NOT 100vh (use content height + padding) so nothing is cut on short viewports.
- 1440: wordmark huge left, lede narrow (2 lines), CTA below; plate ~38vw, `.plate-col` extends to the viewport edge and the plate crosses it by at most 5% of its diameter (modest bleed, matches 1024; never a heavy crop). Overflow clipped on `.stage`/`main` with `overflow-x:clip`, never on body scroll.
**Plate** `<div class="plate" data-plate aria-hidden="true">` (no alt, no role, not focusable). Children `.plate__rings`, `.plate__glaze` (conic pool, uses `--glaze-angle`), reserved `aspect-ratio:1`. Initial CSS = true+glazed (no-JS and reduced-motion state). JS sets off-centre start only when motion allowed.
**Process** `<section id="process" aria-labelledby="process-h">`. Job: show the 3-step method. Eyebrow "How we work"; `<ol class="steps">` of three `<li class="step" data-step="1|2|3">`: numeral `<span class="step__n" aria-hidden="true">01</span>`, `<h3>` Taste/Throw/Glaze, one sentence from Creative Direction. Hairline rule (rim) above each step. 390 and 768 (<1024): stacked, NO svh/vh min-height; each step takes its content height plus one rhythm-gap token (--space-2xl, or 3xl at 768) of block padding, and the hairline rule does the pacing (no plate beside, so no dead paper). 768: text column max ~34ch, numeral left of text (2-col inside step). >=1024: plain scroll, each step about one viewport (min-height ~80svh, accepted because the sticky plate fills the other column), text near the top third.
**Contact** `<section id="contact" aria-labelledby="contact-h">`. Job: close warmly. h2 "Opening, refit or one new dish? <em>Hei</em> is enough." + the same CTA class (repeat of the mailto, now the large email as the display link) + one-line ash caption "Two people answer, usually within a day" (placeholder). Slip mat panel, hairline border, 0 radius. 390 full-bleed mat; >=768 centred mat max ~800px; 1440 spans full grid width, text left, email large right.
**Footer** `<footer>`: "Halde · Bergen, Norge" caps label, mailto repeated as text link, "© 2026". Hairline top. Single row >=768, stacked at 390.
## 5. CTA strategy
One primary action everywhere: mailto. Placements: header (text link), hero (primary button), contact (large link). Primary = glaze ground, clay text (6.28:1), 0 radius, min-height 48px, tracked label; the email is always visible as text (no "Contact us" alone). Luxury-quiet: no pulsing, no sticky floating bar, no pop-ups, no urgency copy.
## 6. Interaction states
| Element | Default | Hover (pointer only, `@media (hover:hover)`) | :focus-visible | :active | Disabled/loading/error |
|---|---|---|---|---|---|
| Text links (nav, footer, contact email) | ink, 1px underline in rim | underline turns glaze, colour glaze | 2px glaze outline, 3px offset, plus 1px clay inner gap (visible on clay and mat) | colour ink, underline thickness 2px | n/a |
| `.cta` | glaze bg / clay text | bg darkens ~8% (#26504C, still >=6.28:1), arrow/underline slides 4px via transform | same glaze ring but offset outline in ink 2px so it shows against glaze | translateY(1px), bg #1F4440 | n/a (no form, no async) |
| `.skip` | off-screen | n/a | visible, ring | n/a | n/a |
Transitions 200ms `power2.out`-equivalent (`cubic-bezier(.22,.61,.36,1)`); reduced-motion: colour changes only. Touch equivalent: there are no hover-only reveals; every hover is cosmetic.
## 7. Accessibility plan
One h1; heading order above. Targets >=44x44 on all links (inline text link in body gets `padding-block` or display:inline-block min-height 44). Contrast pairs: ink/clay 12.70, ash/clay 5.76, ash/slip 4.99, clay/glaze 6.28, glaze/clay 6.28; rim only for graphics. Focus order = DOM order: skip, wordmark, Process, email, hero CTA, contact email, footer email. Plate and numerals aria-hidden. `lang="en"`, Norwegian words wrapped `<span lang="nb">`. No horizontal overflow at 390/768/1024/1440 (test `scrollWidth<=innerWidth`); use `overflow-x:clip` on `.stage`, no 100vw widths (use 100%). Reduced motion: no Lenis, no ScrollTrigger scrub, no reveals, plate true + glazed, all content visible without JS.
## 8. Motion hooks (handoff to gsap-animator / frontend; names are a contract)
- `.plate-col` (>=1024 wrapper, rows 1-2, contains `[data-plate]`; ScrollTrigger must not pin it, CSS sticky only).
- `[data-plate]` the single plate; animate `x,y,rotate` + CSS vars `--ring-blur`, `--glaze-angle` on it; scrub one timeline across `.steps` (trigger `.steps`, start "top 70%", end "bottom 60%").
- `[data-step="1|2|3"]` per step; the glaze fills at step 3 (`--glaze-angle` 0 > 360deg). `[data-step]` content reveals use `[data-reveal]` children (`.step__n`, h3, p), fade+y 16px, 700ms, stagger 80ms, once.
- `[data-reveal]` on hero eyebrow, h1, lede, CTA (order), and contact h2/CTA; never on header, email links after landing, body copy once landed. CTA must be fully visible at load without waiting for JS (set initial hidden state from JS only, never CSS).
- `[data-section="top|process|contact"]` on sections for current-link logic; `[data-nav-link]` on nav anchors.
- <1024: skip the scrub (plate static), only `[data-reveal]` with simple fade. Use `gsap.matchMedia()` with `(min-width:1024px) and (prefers-reduced-motion:no-preference)`.
